### 1.4 Backend Implementation & Architecture
- **FastAPI Endpoints in `backend/app/routes/chat.py` and `backend/app/main.py`**:
  - `POST /ask`: Accepts `ChatQuery(query_text: str)`, returns synchronous `ChatResponse(answer_text: str, retrieved_sources: list[str])`. No streaming SSE implemented.
  - `GET /health`: Returns `HealthStatus(status="ok")`.
  - `POST /retrieval-test`: Accepts `RetrievalTestQuery(query_text: str)`, returns raw `RetrievalTestResponse(chunks: list[ContentChunk])`.
  - `GET /heartbeat`: Returns `{"status": "alive"}`.
  - **Missing**: SSE streaming endpoint mode for `/ask`, and `/analytics` telemetry endpoint.
- **RAG & Model Stack**:
  - Generation: Google Gemini `gemini-2.5-flash` via `google-genai` SDK in `AgentService` (`backend/app/agent/agent_service.py`).
  - Embedding: Cohere `embed-english-v3.0` (1024 dimensions) in `EmbeddingGenerator` (`backend/app/services/embedding.py`).
  - Vector Store: Qdrant Cloud via `qdrant-client` in `RetrieverService` (`backend/app/retriever/retriever_service.py`) and `VectorStore` (`backend/app/services/vector_store.py`).
  - Retrieval filtering: `retrieve_chunks` does not support module filtering; Qdrant payloads do not explicitly store a structured `module` field (only `source_url`, `title`, `text`, `chunk_index`).
- **Ingestion Script (`backend/ingest_docs.py`)**:
  - Scans `ai-book-docs/**/*.mdx`, extracts titles, strips frontmatter/HTML tags, chunks with `chunk_size=350, chunk_overlap=50`, generates Cohere embeddings in batches of 64, recreates the collection, and uploads points.
  - **Missing**: Incremental hash-based auto-ingestion (no file content hashing, no dirty checking, full wipe/re-index).

## 3. Caveats

- **External API Dependencies**: `backend/tests/retrieval/test_retrieval.py` currently tests against live Qdrant and Cohere credentials from `backend/.env`. While it currently passes, automated CI or environments without `.env` credentials will fail unless mocked or guarded by an environment check.
- **Provider Architecture Realignment**: Historical spec 008 listed OpenAI, but the active codebase is implemented with Google Gemini (`google-genai`) and Cohere embeddings (`cohere`). Any mock fixtures or test suites must be consistent with the actual active provider architecture or provide dual provider abstraction.
- **Node.js Package Installation**: Installing `remark-math` and `rehype-katex` will modify `package.json` and `package-lock.json`. Due to Docusaurus 3 using ESM/MDX 3, exact compatible major versions (`remark-math@6`, `rehype-katex@7`) must be used.

# Security Policy

## Supported Versions

We provide security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

We take the security of the **Physical AI & Humanoid Robotics** project and its services seriously.

If you believe you have found a security vulnerability in this repository (e.g. backend API authentication bypass, prompt injection, or unsafe dependency usage):

1. **Do not disclose the issue publicly** in an open GitHub issue or pull request.
2. Please submit a private advisory through GitHub's **Security Advisories** tab or contact the maintainers directly.
3. Include the following details in your report:
   - Type of issue (e.g., SSRF, prompt injection, dependency vulnerability).
   - Step-by-step instructions or proof-of-concept script to reproduce.
   - Any suggested mitigations or patches.

### Response Time
- **Initial Acknowledgment**: Within 48 hours.
- **Triage & Status Update**: Within 5 business days.
- **Remediation Release**: A patched version will be tagged and released as soon as verified.
